# ☕ Projetos Java

Este repositório reúne meus projetos e exercícios desenvolvidos durante meus estudos de **Java**.

A ideia é utilizar este espaço para acompanhar minha evolução na linguagem, desde os primeiros exercícios de lógica de programação até projetos mais completos no futuro.

## 📚 O que estou praticando

Ao longo dos projetos, estou estudando e colocando em prática conceitos como:

* Variáveis e tipos de dados
* Entrada e saída de dados
* Estruturas condicionais
* Estruturas de repetição
* Métodos
* Arrays
* Programação Orientada a Objetos (POO)
* Tratamento de exceções
* E outros conceitos da linguagem Java

## 📂 Organização

Cada projeto possui sua própria pasta e README, explicando seu objetivo e os conceitos utilizados.


## 🎯 Objetivo

Meu objetivo com este repositório é **aprender Java na prática**, registrar minha evolução e construir uma base sólida na linguagem para projetos futuros.

> 🚧 Repositório em desenvolvimento — novos projetos serão adicionados conforme avanço nos estudos.
