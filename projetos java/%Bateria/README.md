# 🔋 Verificador de Bateria em Java

Um programa simples desenvolvido em **Java** que recebe a porcentagem atual da bateria de um celular e informa o estado dela com base em algumas condições.

## 📌 Sobre o projeto

Este foi um dos meus primeiros exercícios práticos utilizando Java.

O programa solicita ao usuário a porcentagem atual da bateria e, através de estruturas condicionais, classifica a bateria em quatro estados:

* 🔋 **Excelente** — acima de 70%
* 🔋 **Normal** — acima de 40%
* 🪫 **Fraca** — acima de 20%
* 💀 **Morta** — 20% ou menos

## 🧠 Conceitos praticados

Neste projeto pratiquei:

* `Scanner` para entrada de dados
* Declaração e utilização de variáveis
* Tipo `int`
* `System.out.println()`
* Estruturas condicionais `if`, `else if` e `else`
* Operadores de comparação
* Fechamento do `Scanner`

## 💻 Exemplo de execução

Qual a porcentagem atual da sua bateria?
65

Bateria atual: 65% De Bateria
Sua bateria esta normal!


## 🚀 Objetivo

O objetivo deste exercício foi praticar a lógica de programação utilizando Java e começar a desenvolver programas que recebem informações do usuário e tomam decisões com base nesses dados.
