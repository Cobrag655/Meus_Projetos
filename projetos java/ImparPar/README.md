# 🔢 Par ou Ímpar

Um pequeno projeto desenvolvido em **Java** para praticar conceitos básicos de lógica de programação e estruturas condicionais.

O programa recebe um número inteiro informado pelo usuário, calcula o resto da divisão por 2 e determina se o número é **par ou ímpar**.

## 🧠 Conceitos praticados

* `Scanner` para entrada de dados pelo terminal
* Variáveis do tipo `int`
* Operador módulo `%`
* Estruturas condicionais `if / else`
* Comparação de valores
* Saída de dados com `System.out.println()`

## ⚙️ Como funciona

O usuário informa um número:

Qual numero você quer saber se é par ou impar?
2398

O programa calcula:

2398 % 2 = 0


Como o resto da divisão é `0`, o número é identificado como par:


Logo o seu numero é Par!


Caso o resultado seja diferente de `0`, o programa informa que o número é ímpar.

## 💻 Exemplo


Qual numero você quer saber se é par ou impar?
17

O numero 17 dividido por 2 é igual a: 1!
Logo o seu numero é Impar!
